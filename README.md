# Asteroids
![1](https://github.com/user-attachments/assets/80a09f4d-6295-45fb-858f-5950104ec504)

Популярное [Тестовое](https://docs.google.com/document/d/1D01HZPMvkGane1dUWSF63XwmhMgp51GjESNff3lG5aI/edit?usp=sharing) для студии Kefir. В определенный момент перестал его придерживаться и продолжил разработку в "вольном стиле".

В проекте заложена основаная кодовая база, опираясь на которую, далее можно достроить любое количество разнонаправленного контента, сохраняя при этом модульность, тестируемость и простоту понимания.

Примерный Стек используемых на текущий момент технологий и паттернов:
StateMachine, DI(Zenject), Addressables, UniTask, UniRx(new R3 lib), MVC, MVP, Facade, Interface hiding, Local configs(ScriptableObjects), Remote configs, Signal Bus(own implementation), Adaptive Input(Mobile, Pc), Adaptive Asset and Scene Loading, Async Factories + ObjectPool, GameAnalytics, IronSource...
