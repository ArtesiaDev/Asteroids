# Asteroids
![1](https://github.com/user-attachments/assets/80a09f4d-6295-45fb-858f-5950104ec504)

Взял за основу популярное [тестовое от студии Kefir](https://docs.google.com/document/d/1D01HZPMvkGane1dUWSF63XwmhMgp51GjESNff3lG5aI/edit?usp=sharing) и частично реализовал его. В определенный момент перестал его придерживаться и продолжил разработку в "вольном стиле".

На данный момент в проекте отсутствуют несколько геймплейных фичей и настроек. Основаная кодовая база, опираясь на которую, можно достроить любое количество разнонаправленного контента была заложена.

Примерный Стек используемых на текущий момент технологий, подходов и паттернов:
StateMachine, DI(Zenject), Addressables, UniTask, UniRx(new R3 lib), MVC, MVP, Facade, Interface hiding, Local configs(ScriptableObjects), Remote configs, Signal Bus(own implementation), Adaptive Input(Mobile, Pc), Adaptive Scene Loading, Async Factories + ObjectPool, GameAnalytics, IronSource...
